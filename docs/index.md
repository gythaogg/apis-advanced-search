# APIS Advanced Search

A query builder for [APIS](https://github.com/acdh-oeaw/apis-core-rdf) instances. It lets you build queries across entities and relations without writing Django ORM code.

!!! note "About the screenshots"

    The screenshots come from APIS instances where this package is installed. They show the interface only. The records and results shown are incidental. Do not read them as data, and do not draw conclusions from them.

## Where to start

**Researchers**

1. Read [Simple search](search/simple-search.md) for the basic workflow.
2. Use [Relation search](search/relation-search.md) and [Groups](search/groups.md) for more complex queries.
3. Choose columns with [Columns](search/columns.md).

**Developers**

1. [Install and configure](developers/installation.md) the package.
2. Review the [settings](developers/settings.md).

Features under **Beta features** work, but their interface and behaviour may change.
